Typ liczony po `typeId` jednostki (nie po nazwie). Reguły i walidacja istniejące (limit, przynajmniej jedna zostaje, przycisk potwierdzenia aktywny/nieaktywny, aria) działają bez zmian po zaznaczeniu skrótem. Przy 50+ jednostkach lista dalej się przewija, a rząd chipów zostaje widoczny u góry (sticky) i nie łamie układu na 1280×720 ani w wąskim oknie; chipy mają dostępność (button, aria-pressed, fokus klawiaturą).
