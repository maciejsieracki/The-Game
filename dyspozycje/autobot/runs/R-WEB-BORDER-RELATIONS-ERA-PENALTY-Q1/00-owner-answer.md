# Echo decyzji właściciela — 2026-11-10

Decyzja dla par o różnych epokach: użyć wyższej epoki (`max(epochA, epochB)`). Wynik: Kamień–Kamień = −2/turę; Kamień–Brąz = −3/turę; Brąz–Żelazo, Kamień–Żelazo i Żelazo–Żelazo = −4/turę. Właściciel wskazał: „Wyższą: w tej parze −4/turę”.

Zachowuję aktualny warunek wspólnej granicy i >2 miasta dla obu stron. Ta reguła jest symetryczna i powinna dać ten sam rezultat niezależnie od kolejności ownerów.
