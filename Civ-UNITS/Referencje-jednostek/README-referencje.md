# Referencje jednostek — biblioteka stylu wizualnego

Folder zawiera obrazy referencyjne (wzorcowe) do wyglądu jednostek w grze.

## Styl docelowy

**Styl Roblox** — klockowy awatar (humanoid z prostych brył) z nałożonym szczegółowym pancerzem, hełmem, bronią i peleryną na bazowym ciele. Czyste teksturowanie. Jest to **minimum akceptowalnej jakości wizualnej jednostek** w grze (patrz `PROJEKT-GRY-master.md` §9a Styl jednostek).

## Jak korzystać z biblioteki

Przeglądaj obrazy poniżej i używaj ich jako wzorca przy tworzeniu assetów 3D/2D jednostek. Pierwszeństwo mają pliki oznaczone jako **STYL DOCELOWY** — to są wzorce produkcyjne dla v0.1/v0.2.

## Kategorie statusu

- ✅ **STYL DOCELOWY** — wzorzec do produkcji assetów v0.1/v0.2; te referencje są priorytetem.
- ⏳ **Późniejsze (Średniowiecze)** — do wdrożenia w kolejnych epokach; zachowaj jako referencję.
- ⏳ **Przyszłe epoki** — dotyczy mechanik lub epok niezaimplementowanych w v0.1.
- ⏳ **Przyszłe kultury** — Galowie, Germanie — planowane jako nowe cywilizacje w kolejnych iteracjach.
- ⏳ **Przyszłe moduły** — wymaga modułu dyplomacji/szpiegostwa (do zdefiniowania później).
- ⛔ **Pominąć** — odrzucone z przyczyn projektowych (np. brak środkowej części, niekompletny model).

## Mapowania jednostek (z referencji do mechaniki gry)

- **Jaguar** (ref-18) → jednostka aztecka: Topornik lub Maczugowiec (Aztekowie/Inkowie — cywilizacje Mezoameryki)
- **Nieśmiertelni** (ref-08) → Sumerowie / kolejne epoki (elita Sumerów lub ogólna elita późniejszych epok)
- **Miecznik Galów** (ref-17) → Galowie (przyszła kultura, razem z Germanami)
- **Szpieg/Zabójca** (ref-07, ref-20) → jednostka specjalna zdolna eliminować generałów i wybrane jednostki (moduł szpiegostwo/dyplomacja)
- **Chłop z widłami** (ref-22) → Milicja wieśniaków (obrona miasta przy ataku; siła ~1/2 wojownika Ep. Kamienia)
