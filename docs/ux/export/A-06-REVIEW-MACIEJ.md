## Co oceniasz (2 haki)

### Hak 1 — Treść / funkcja (układ panelu)

Czy na panelu **powinno być** to, co widać?

| Element | Jest w szkicu | Twoja ocena |
|---------|---------------|-------------|
| Nagłówek: Armia + współrzędne heksu | tak | |
| Liczba jednostek na heksie | tak | |
| Karty stosu (przełączanie jednostki) | tak | |
| HP + ruch na karcie | tak | |
| Staty: Atak, Obrona, Ruch, Zasięg | tak | |
| Akcje: Ruch, Ufort., Pomiń | tak | |
| Rozdziel / Połącz / Lista | tak | |
| Zamknięcie panelu | tak | |

**Odpowiedź:** `A-06 treść OK` · albo lista: „usuń X”, „dodaj Y”

---

### Hak 2 — Wygląd (stary vs szkic vs design)

| Werdykt | Co robimy |
|---------|-----------|
| **A — nadal stare** | Szkic nie wystarcza → **Design** mockup 1E → lane v2 |
| **B — już nowe, zostaw** | **Koniec A-06** — w grze zostaje szkic, **bez designera** |
| **C — układ OK, wygląd słaby** | Ty podajesz poprawki → **lane poprawka** → PNG → potem **Design** |

**Odpowiedź:** `A-06 wygląd A/B/C` + ewentualnie uwagi

---

## Kolejność (ustalone z Maciejem)

```
1. Szkic lane → PNG do Ciebie
2. Hak 1: treść OK?
3. Hak 2: wygląd A / B / C?
4. (opcjonalnie) lane poprawki treści/wyglądu → PNG
5. (jeśli A lub C) Design mockup 1E
6. Lane v2 z mockupu → master
```
