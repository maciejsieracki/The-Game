Zasada — jedno źródło

class-* (4) → górny pasek, morale, pre-bitwa, Strategia, Formacja (mapa battle-class-map.json). unit-* (18) → roster, miasto, encyklopedia (mapa unit-icon-map.json + aliasy nazw z gry). Rail/Taktyka = inline SVG chrome. Wszystko currentColor — kolor z kontekstu (Ty #3a6ad0 / wróg #c84040 / złoto #e8d88a). Cursor: podłącz iconRegistry raz do tych plików — bez dublowania ścieżek.
