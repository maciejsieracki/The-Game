# The Game — kontekst dla Brand Book

**Gra:** strategia turowa 4X · epoki Kamień → Brąz → Żelazo · mapa heksagonalna · miasta · armie · dyplomacja · nauka.

**Gracz:** buduje imperium, rozwija miasta, prowadzi wojny i negocjacje, wygrywa przez dominację (meta).

**UI — zakres wizualny:**
- Menu główne i kreator nowej gry (5 kroków)
- HUD mapy (zasoby, tura, toolbar)
- Panel miasta (produkcja, budowa, rekrut, zasoby)
- Dyplomacja (lista, audiencja, modale)
- Walka (pre-bitwa, pole bitwy 3D, oblężenie)
- Overlaye końca gry

**Klimat wizualny (decyzja Macieja 1B):**
- Ciemne tło nocnego imperium — **`#080a12`**
- Ciepłe złoto **`#e8d88a`** — akcenty, ramki, tytuły
- Tekst pergaminowy — nie chłodny biały
- Styl: **premium historyczny**, nie sci-fi, nie flat corporate
- Inspiracja: klasyczne imperium · pergamin · heraldyka · dostojne menu

**Język UI:** polski (etykiety chipów, przyciski, tooltips).

**Co NIE jest celem brand booka:**
- Zmiana gameplayu
- Nowe emoji jako ikony finalne
- Grube „szablony WWW” z pełnym wypełnieniem złotem (przyciski = **outline 4C**)

**Kolejność wdrożenia ekranów (po brand booku):** menu → HUD → panel miasta → dyplomacja → walka.

**Platforma docelowa:** gra w przeglądarce (HTML/CSS/TS), canvas 1920×1080 jako referencja layoutu.
