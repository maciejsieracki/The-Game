## Pytania ABC do Macieja (odpowiedź jedną linią, np. `T1A T2B T3A T4A`)

### T1 — Trybut co turę (gdy AI/gracz zaakceptuje)

- **A)** Odejmuj z **skarbca państwa** (`player.pieniadz`); brak środków = zerwanie traktatu + casus belli *(rekomendacja EKO+CYW)*
- **B)** Odejmuj proporcjonalnie z miast (wealth per-city)
- **C)** Tylko **jednorazowa** płatność przy akceptacji (bez co-tur)

### T2 — Sojusz wojskowy

- **A)** **Defensywny** — wchodzisz w wojnę tylko gdy sojusznik **zaatakowany** *(rekomendacja v1.1)*
- **B)** **Pełny** — atak sojusznika = obowiązek wojny (jak TW)
- **C)** Sojusz **tylko symboliczny** v1.1 (+Relacja, bez auto-wojny) — pełna logika v1.2

### T3 — Handel (akcja 5)

- **A)** **Jednorazowa** wymiana (surowiec / pieniądze) + bonus relacji *(prostsze v1.1)*
- **B)** **Umowa co turę** (X pieniędzy/turę przez N tur) — wymaga EKO tick
- **C)** Oba warianty w UI (wybór przy negocjacji)

### T4 — Kolejność wdrożenia v1.1

- **A)** Faza 1: **NAP + trybut + handel pełny** → Faza 2: sojusz + namów → Faza 3: granice, tech, ultimatum, wasal *(rekomendacja)*
- **B)** Wszystko naraz (1 sprint)
- **C)** Tylko NAP + trybut; reszta v1.2
