# R-ARMIA-KONCENTRACJA-AI-BARB-Q1 — decyzja właściciela

**Data zapisu:** 2026-08-20
**Status:** ECHO zapisane; gotowe do implementacji

Właściciel wybrał warianty **4A / 5A / 6A / 7A**:

- wspólny, owner-agnostyczny model: kwalifikacja → deterministyczny punkt zbiórki → ruch istniejącym pathfindingiem → marsz/atak po faktycznym zgrupowaniu;
- koncentracja od minimum **3 kwalifikowanych jednostek w promieniu 4 heksów**, a marsz/atak po faktycznym stosie minimum **3**;
- barbarzyńcy zachowują obecny lokalny rally przy żywym obozie, bez rozszerzenia między obozami i na rajdy morskie;
- kwalifikowane są aktywne lądowe jednostki bojowe; wykluczone są zwiadowcy/cywile, garnizony, jednostki zaokrętowane, oblężone i rajderzy morscy.

Granice: nie teleportować jednostek, nie zwiększać sztucznie Mocy, nie zmieniać istniejącego rally barbarzyńców poza tym zakresem. Główne cywilizacje AI mają korzystać z istniejącego pathfindingu i faktycznego rosteru.
