# R-UI-RELACJA-DEAL-MOD — widoczny wpływ Relacji na deal (2026-08-03)

Panel PW dyplomacji pokazuje wiersz **„Wpływ Relacji na deal”** we wszystkich wariantach (stół negocjacji, koszyk handlu, traktat). Relacja 100 = punkt balansu; powyżej 100 deal tańszy (max −90% do progu PN traktatu); poniżej 100 droższy (max +90%). Handel bez traktatu: Relacja ≥100 = parytet 1:1, poniżej — wyższy fair-min. Kolory: zielonkawy (korzyść), pomarańczowy (kara), neutralny (balans). Tylko UI — wzór silnika bez zmian.
