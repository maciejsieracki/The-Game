## B-KULT-REL-Q4 — Cel gry (custom C)

**Decyzja Macieja:** **C (custom)**

> Kultura **i relikie** dodane do **Power** (wpływ na zwycięstwo przez dominację Power); **bez** pełnego zwycięstwa kulturowego na razie.

**Implementacja:** dwa nowe składniki w `computeObjectivePower` — patrz propozycja formuły w audycie §10 i poniżej.

**Uwaga audytu:** osobny system „relikii" jako przedmiotów **nie istnieje** w kodzie v1. Do Power liczymy **ukończone cuda świata** (`placedWorldWonders` / `completedWorldWonders` z `ownerId`) jako artefakty imperium; przyszłe relikie = osobna decyzja.

**Pliki:** `gra/src/game/power-objective.ts`, `gra/data/power-params.json`, `gra/src/main.ts` (`buildObjectivePowerForOwner`), `gra/src/ui/powerOverlayHud.ts`, `power-objective-test.cjs`.

## Propozycja formuły Power (Q4C)

Kalibracja odniesienia: scenariusz ep.1 ~3020 Power (`power-params.json` §kalibracja). Nowe składniki ~8–12% bazy każdy przy typowej grze kulturowej.

```typescript
// W buildObjectivePowerForOwner (silnik) — surowe liczniki:
const sumaKulturyImperium = cities
  .filter(c => c.ownerId === ownerId)
  .reduce((s, c) => s + Math.floor(c.kultura ?? 0), 0);

const cudaAktywne = placedWorldWonders.filter(
  w => w.ownerId === ownerId && !wonderIsRuin(w.wonderId, ownerId),
).length;
const cudaRuina = placedWorldWonders.filter(
  w => w.ownerId === ownerId && wonderIsRuin(w.wonderId, ownerId),
).length;

// W computeObjectivePower — nowe wiersze (współczynniki z power-params.json):
row('kultura', 'Kultura imperium',
  Math.floor(sumaKulturyImperium / 100), coeff.kulturaSetka),  // np. 12 pkt / 100 kultury
row('relikie', 'Relikie (cuda)',
  cudaAktywne, coeff.relikAktywny),                             // np. 80 pkt / cud
// opcjonalnie osobna linia lub coeff×0.25:
// cudaRuina × coeff.relikRuina                                   // np. 20 pkt / ruina
```

**Proponowane współczynniki startowe (Panel-B / JSON):**

| Klucz JSON | pkt | Efekt @ normal |
|------------|-----|----------------|
| `kultura_setka` | 12 | 500 skumulowanej kultury → 60 pkt (~1 miasto) |
| `relik_cud_aktywny` | 80 | 1 cud aktywny → 80 pkt (~1.6 miasta) |
| `relik_cud_ruina` | 20 | cud po epoce absolut → 20 pkt |

Zwycięstwo: bez zmian w `victory.ts` — dominacja nadal `Power > 50%` w ostatniej epoce; kultura/cuda **podbijają ranking**, nie dodają trzeciego ekranu końca.
