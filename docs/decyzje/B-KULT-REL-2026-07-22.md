## Propozycja formuły Power (Q4C)

Kalibracja odniesienia: scenariusz ep.1 ~3020 Power (`power-params.json` §kalibracja). Nowe składniki ~8–12% bazy każdy przy typowej grze kulturowo-religijnej.

**Istniejące składniki Power** (`power-objective.ts`): armia, bitwy, ludki, rekruci, miasta, terytorium, budynki, tech, ulepszenia, zdobycze. Świątynie są już w „budynki" — **nie** liczymy ich ponownie w religii.

```typescript
// W buildObjectivePowerForOwner (silnik) — surowe liczniki:
const ownerCities = cities.filter(c => c.ownerId === ownerId);
const stateReligion = ownerReligionForOwnerId(ownerId); // civReligionForKey

const sumaKulturyImperium = ownerCities
  .reduce((s, c) => s + Math.floor(c.kultura ?? 0), 0);

const religionEntries = ownerCities.map(c => ({
  state: resolvedCityReligion(c),
}));
const agg = aggregateReligionEmpire(religionEntries, stateReligion);
// agg.sharePct = % wiernych wiary państwowej w całym imperium (0–100)

const miastaWlasnaWiara = ownerCities.filter(c => {
  const dom = dominantReligion(resolvedCityReligion(c), religionParams);
  return dom.status === 'dominant' && dom.religion === stateReligion;
}).length;

// W computeObjectivePower — nowe wiersze (współczynniki z power-params.json):
row('kultura', 'Kultura imperium',
  Math.floor(sumaKulturyImperium / 100), coeff.kulturaSetka),       // np. 12 pkt / 100 kultury
row('religia', 'Religia państwowa',
  Math.floor(agg.sharePct / 10), coeff.religiaDziesiatka),          // np. 15 pkt / każde 10% wiernych
row('religia_miasta', 'Miasta z własną wiarą',
  miastaWlasnaWiara, coeff.religiaMiasto),                           // np. 10 pkt / miasto z dominującą wiarą państwa
```

**Proponowane współczynniki startowe (Panel-B / JSON):**

| Klucz JSON | pkt | Efekt @ normal (8 miast, 80% wiernych, 500 kultury) |
|------------|-----|-----------------------------------------------------|
| `kultura_setka` | 12 | 500 kultury → 60 pkt (~2% bazy) |
| `religia_dziesiatka` | 15 | 80% wiernych → 8×15 = **120 pkt** (~4% bazy) |
| `religia_miasto` | 10 | 6 miast z własną wiarą → **60 pkt** (~2% bazy) |

**Razem kultura+religia @ typowej grze:** ~240 pkt (~8% bazy 3020) — spójne z celem „żaden składnik nie dominuje".

**Uwagi projektowe:**
- Religia nagradza **zjednoczenie wiary** (szerzenie, konwersja po podboju Q2), nie sam fakt posiadania świątyni.
- Miasta z obcą dominującą wiarą = 0 pkt z linii `religia_miasta` — motywacja do konwersji.
- Cuda świata pozostają poza tym składnikiem (osobny temat, jeśli kiedyś relikie/artefakty).

Zwycięstwo: bez zmian w `victory.ts` — dominacja nadal `Power > 50%` w ostatniej epoce; kultura i religia **podbijają ranking**, nie dodają trzeciego ekranu końca.
