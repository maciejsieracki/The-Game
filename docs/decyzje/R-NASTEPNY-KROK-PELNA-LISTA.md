**Status:** 🟢 KANON

**Cytat Macieja:** „Limit max 3 dotyczył tylko pytań ABC, ale zdjąłem tą blokadę.” · wcześniej: „Wypisz wszystkie następne kroki… a nie rzucasz po trzy.”

## Reguła

1. **### Następny krok** — wypisz **wszystkie** widoczne kolejne prace (kod/dane/docs/deploy-prep), nie ucinaj do 3.
2. Pierwsza pozycja = rekomendacja (najpilniejsza).
3. Numeracja ciągła `1…N`. Na końcu: `Napisz: działaj / 1 / 2 / … / N (albo inną dyspozycję).`
4. **### Playtesty** nadal osobno (`R-NASTEPNY-KROK-SPLIT`) — nie mieszać z kodem.
5. Limit „max 3” dotyczył **wyłącznie ABC** i jest **wycofany** (`R-ABC-PELNA-LISTA`).
