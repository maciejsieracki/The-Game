## B-SPIC-Q1 — Co daje tier II wojsku (Spichlerz II)?

**Pytanie:** Co daje Spichlerz II wojsku? A = cap 150 · B = tylko bufor 70% · C = wszystko naraz (+ Zd/Sz lokalnie).

**Decyzja Macieja:** **C**

> „Cap 150 **i** bufor 70% — wszystko naraz; bonusy Zd/Sz lokalnie w mieście z tierem II."

**Implementacja (plan):** Spichlerz II: `spichlerz_ii_zachowanie=0,7`, cap armii **+150** 🍞/spichlerz (zastępuje 100), **+2 Zd / +2 Sz** lokalnie (zastępuje bonus I). Źródło kanonu: `SUROWCE-KANON-2026-07-22.md` § Spichlerz two-tier.

**Pliki docelowe:** `buildings.json`, `society-params.json`, `turn-economy.ts` / empire-food, `cityPanel.ts` (UI tier).

## B-SPIC-Q2 — Bonus soli: gdzie działa?

**Pytanie:** Bonus soli: A = tylko miasto ze Spichlerzem II · B = miasta z warzelnią · C = całe imperium.

**Decyzja Macieja:** **A**

> „Bonus soli / konserwacji — **tylko** w mieście ze **Spichlerzem II** (nie całe imperium, nie każda warzelnia)."

**Implementacja (plan):** Efekt welfare z soli powiązany z tierem II w danym mieście, nie ze stockiem imperium.

## B-SPIC-Q3 — Zasięg bonusów budynków vs surowców

**Pytanie:** Zasięg bonusów: A = budynki lokalnie / surowce imperium · B = wszystko lokalnie · C = wszystko imperium.

**Decyzja Macieja:** **A**

> „Bonus z **budynku** = lokalnie w mieście; bonus z **aktywnego dostępu do surowca** = zasięg imperium (nie magazyn stock)."

**Implementacja (plan):** Reguła ogólna z `SUROWCE-KANON` § „Reguła ogólna — każdy budynek i surowiec daje bonus".

## B-SPIC-Q4 — Upgrade Spichlerz I → II

**Pytanie:** Upgrade II: A = kolejka produkcji · B = instant za sól · C = auto przy dostępie.

**Decyzja Macieja:** **A**

> „Upgrade do Spichlerza II przez **kolejkę produkcji** miasta (jak budowa), nie instant za sól ani auto-upgrade."

**Implementacja (plan):** Pozycja produkcji / upgrade path w `production.ts` + bramka aktywnej soli.

## B-SPIC-Q5 — Wyjątki: infrastruktura bez bonusu Sz/Zd

**Pytanie:** Każdy element musi mieć bonus? A = zero wyjątków · B = infrastruktura bez Sz/Zd · C = surowce pośrednie bez bonusu.

**Decyzja Macieja:** **B**

> „**Infrastruktura** (drogi, mury czyste, itp.) **bez** bonusów Sz/Zd; budynki produkcyjne i Spichlerz — z bonusami wg kanonu."

**Implementacja (plan):** Tag kategorii w `buildings.json` lub lista wyjątków; Spichlerz I/II **ma** bonusy (+1/+1, +2/+2 — już zamknięte 2026-07-22).
