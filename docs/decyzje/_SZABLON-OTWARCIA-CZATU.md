## Minimalna wersja (jeśli już znasz temat)

```
Grupa <A|B|C|D|E>. Temat <ID>. Ekran: <EKRAN>. Lane: <LANE>.
Obowiązuje docs/czaty/GRUPA-X-….md + docs/decyzje/DYSPOZYCJA-STALA.md.
Zacznij od charteru grupy, potem docs/decyzje/<ID>-*.md.
Pytaj Macieja TYLKO o tematy z charteru.
```
