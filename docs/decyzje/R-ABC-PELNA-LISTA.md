# R-ABC-PELNA-LISTA — wypisuj wszystkie pytania naraz (2026-08-06)

**Status:** 🟢 KANON  
**Cytat Macieja:** „a co do pytań ABC, to nie rób zasady, że tylko 3 pytania, tylko wypisuj od razu wszystkie pytania, które masz w pełnej liście, ale z koniecznością dobrej numeracji. Zapisz do zasad.”

## Reguła

1. **ZAKAZ limitu „max 3 pytania na paczkę”** (stara reguła 2026-07-04 — **wycofana**).
2. Gdy masz kolejkę ABC — wypisz **od razu wszystkie** pytania z pełnej listy w **jednej wiadomości**.
3. **Numeracja obowiązkowa:** `[1/N]`, `[2/N]`, … + **pełne ID** (`R-…-Q1`). Nagłówek: `[LISTA ABC — N pytań]` + spis ID.
4. Każde pytanie: pełny format (Sytuacja · Cel · Dlaczego teraz · A/B/C + Za/Przeciw · Rekomendacja).
5. Tekst w kanale — **BEZ** popupów AskQuestion (ład 2026-07-06).
6. Nadal obowiązuje: **R-ABC-BEZ-PLAYTEST** · pełne nazwy · ECHO po odpowiedziach.

## Odpowiedź Macieja

Może pisać litery w kolejności (`A B C …`) albo `ID=litera` per pozycja. Agent ECHO wszystkich naraz.
