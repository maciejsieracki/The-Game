# R-NASTEPNY-KROK-SPLIT — Playtesty vs kod (2026-08-06)

**Status:** 🟢 KANON  
**Cytat Macieja:** „odróżniaj w następnych krokach playtesty od dalszych działań w kodzie. Zaznaczaj to w podpunktach. A najlepiej rozdzielaj na Play Testy i następny krok gdzie są tylko kolejne zmiany bo to zamydla mi obraz.”

## Format obowiązkowy (koniec odpowiedzi agenta)

### Playtesty
Tylko rzeczy do ogrania / sprawdzenia **w grze** przez Macieja (wejście, md5, co kliknąć).  
Bez mieszania z implementacją. Maciej wie, że ma testować — to **lista weryfikacji**, nie pytanie ABC.

### Następny krok
Tylko **dalsze zmiany w kodzie / danych / docs** (co agent może zrobić po sygnale).  
Bez pozycji typu „git pull + sprawdź w grze”.  
**Pełna lista** wszystkich widocznych prac — **bez limitu 3** (`R-NASTEPNY-KROK-PELNA-LISTA`; limit 3 dotyczył tylko ABC i jest wycofany).

## Zakaz
Mieszać w jednym numerowanym menu: „1. sprawdź Escape · 2. koduj X · 3. hover”.
