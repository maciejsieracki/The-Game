# R-ABC-BEZ-PLAYTEST — zakaz pytań ABC o playtesty

**Status:** 🟢 KANON (2026-08-06)  
**Cytat Macieja:** „nigdy w pytaniach A-B-C nie zadawaj pytania o play testy. Wiem że mam je zrobić. Zadawaj pytania o błędy i rzeczy które potrzebują odpowiedzi żeby generować kod.”

## Reguła (NIENEGOCJOWALNE)

1. **ZAKAZ** formułować paczki ABC, których celem jest: „czy playtestujesz?”, „OK/BUG teraz?”, „odłożyć playtest?”, „zamknąć bez playtestu?”.
2. Maciej **sam** wie, że ma ogrywać ROBOCZA; agent **nie** pyta o to literami A/B/C.
3. ABC wolno zadawać **tylko** gdy odpowiedź jest potrzebna do **generowania kodu / danych / architektury** albo rozstrzygnięcia błędu/produktu (opcjonalnie operacyjne bez playtestu).
4. Statusy „CZEKA playtest” w rejestrze wolno aktualizować **po** werdykcie Macieja w czacie (`OK` / `BUG: …`), nie przez pytanie ABC „czy zrobisz playtest”.

## Skutek dla agentów

- Nie wrzucać playtestu do paczek „co dalej z tematem X”.
- Zamiast tego: konkretne luki produktowe, liczby, zakres fixa, wariant UI — rzeczy blokujące kod.
